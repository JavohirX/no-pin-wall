# NoPinWall Privacy Policy

Last updated: November 19, 2026

NoPinWall does not collect, store, sell or transmit any personal data or browsing data.

- **No network requests.** The extension never contacts any server, including its developer's.
- **No analytics, telemetry or tracking.**
- **No storage.** It doesn't use cookies, `localStorage` or `chrome.storage`.
- **No permissions.** The manifest requests no extension permissions.
- **Pinterest only.** Its content script runs only on Pinterest domains, where it hides the login popup and restores scrolling. It does not read your pins, searches or account details.

The source code is public in this repository, so you can check every line of this.

Questions: [open an issue](https://github.com/JavohirX/no-pin-wall/issues).
